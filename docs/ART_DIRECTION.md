# 猫の見た目・確定仕様

## 基準にするデザイン

依頼者が描いた猫のスケッチをデザインの参考にする。原画をそのまま画像素材として使用するのではなく、線のガタつきと太さを整え、おてての形・左右のつながり・重なり・指先を修正して清書する。

ふわふわした輪郭、小さく素朴な丸目、やわらかい口元、首輪と鈴、ふさふさのしっぽを残す。頭と胴体の比率は依頼者の絵を基準にし、以前の大きな頭には戻さない。手描きの素朴さは残すが、線の交差や描きかけのような線は残さない。

## 同梱する4種類

- キジトラ：茶灰色の毛に濃い縞。
- 茶トラ：茶色・オレンジ系の毛に濃い縞。
- 白猫：白い毛。
- 黒猫：黒い毛。目は背景から識別できる小さな丸目。

## 共通条件

- リアルな虹彩、大きな白目、光沢の強い目は使用しない。
- 頬に赤みやチークを入れない。
- 通常の猫とお部屋の画像に名前・説明文・吹き出しを入れない。
- 例外として、眠っているときの Zzz は可愛い表現として残す。以前の Z 禁止の指定より、この条件を優先する。
- 操作メニューと手順書の文字は操作性のために残す。
- 猫素材と動作ロジックを分離し、後から差し替えられる構成を維持する。

## 納品方針

依頼者への見た目の検品・承認依頼は不要。この仕様に沿って実装して納品する。動作と入力検証の自動テストは省略しない。
GitHubの安全性チェックで書き込みがブロックされた場合は、その時点で作業を停止して報告する。
