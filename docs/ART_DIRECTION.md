# 猫の見た目・確定仕様

このファイルは依頼者の指定を保守時にも維持するための仕様です。

## 同梱する4種類

- キジトラ：茶灰色の毛に濃い縞。
- 茶トラ：茶色・オレンジ系の毛に濃い縞。
- 白猫：白い毛。
- 黒猫：黒い毛。目は素朴な丸目のまま背景から識別できる色にする。

## 全種類に共通する条件

- イラスト調で、ふわふわのやわらかい輪郭にする。
- 頭は初期案よりほんの少し小さくする。
- 小さく素朴な丸目。リアルな虹彩、大きな白目、光沢の強い目は使用しない。
- 頬に赤み・チークを入れない。
- 猫とお部屋の画像に文字を入れない。名前、説明、吹き出し、睡眠の Z なども描かない。
- 通常の猫・お部屋表示には説明文や状態ラベルを重ねない。操作メニューと手順書の文字は操作性のために残す。
- 猫の画像は動作ロジックと分離し、後から差し替えられる構成を維持する。

## 納品方針

依頼者への見た目の検品・承認依頼は不要。この仕様に沿って実装し、そのまま納品する。
動作・安全性のための自動テストは省略しない。
