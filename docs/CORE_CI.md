# コア部分のOS別自動テスト

このPRには、v0.1.0のアーカイブから復元したmodel.py、storage.py、packs.pyと、対応する42テストを追加しています。各モジュールとJSONひな型はアーカイブとGit blobのハッシュが一致することを確認しました。

42件は歩行・状態遷移13件、設定保存8件、PNG/JSON素材パック検証21件です。元の44件のうち、旧SVG画像と全ランタイムモジュールを対象にした静的検査2件はこのコア用スイートに含めません。素材がないのにSVG検査を合格にすることを避けています。

## 実行方法

```sh
python -m unittest discover -s tests -p test_platform_core.py -v
```

Python標準ライブラリだけで実行できます。Qtやpip依存は不要です。PNGテストにはテスト内で生成した無地の画像を使います。pack.jsonの「こむぎ」は旧フォーマットのテスト用の名前で、採用した猫デザインではありません。

## 自動実行

GitHub ActionsでUbuntu 24.04、Windows Server 2022、macOS 15のARM64とIntel環境に対して実行します。Pythonは3.12です。42テストのログと実際のOS/CPUアーキテクチャをArtifactsに14日間保存します。シンボリックリンクを作成できないホストでは、その1項目はスキップと表示されます。

ワークフローを追加しただけでは合格とはしません。Actionsの各実行結果・ログで判定します。

## 確認できないこと

Windows Server上の成功はWindows 11実機の成功ではありません。GitHubのホスト環境は依頼者の実機でもありません。GUIの起動、透明ウィンドウ、モニター切替、スリープ復帰、画像やZzzの表示、GPU/メモリ/CPU使用量、採用画像の組み込み、アプリの配布ビルドはこの42テストの対象外です。
