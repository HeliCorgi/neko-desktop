## 猫のビジュアル

依頼者が承認した、前足と胸元を修正した版を採用します。上の画像はそのキジトラを切り出して128×128に縮小したものです。描き直していません。

キジトラ・茶トラ・白猫・黒猫の4種類。小さな丸目、頬の赤みなし、鈴の中の形はT型。通常は文字なし、寝ているときだけZzzを残します。
